# Kabilan V.S

This is my **first web project**, created using **HTML, CSS, and JavaScript**.  
The website displays short gaming stories in a simple and interactive way.

---

## 📖 About the Project

This project is a **gaming story display website** where users can:
- Read short game-related stories
- Enjoy a clean and simple UI
- Experience basic interactivity using JavaScript

It helped me understand the fundamentals of **web development** and how HTML, CSS, and JavaScript work together.

---

## 🛠️ Technologies Used

- **HTML** – Structure of the website  
- **CSS** – Styling and layout  
- **JavaScript** – Interactivity and dynamic content  

---

## ✨ Features

- 📜 Short gaming story display  
- 🎨 Simple and clean design  
- ⚡ Basic JavaScript interactions  
- 📱 Beginner-friendly structure
